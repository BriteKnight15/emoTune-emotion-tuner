# emoTune-emotion-tuner
Repository for iOS app emoTune: emotion tuner
It is worth explaining why this repository has only two commits. For all of the software development of the app, I used a private repository because my code used my OpenAI API key. I was not comfortable publishing that, so I created a new public repository that is almost identical; the only difference is the variable declared on line 38 of the ContentView.swift file. This variable’s definition was changed from the API key to the following string: "INSERT API KEY HERE".

For this reason, any demos of the code from this repository will need to rewrite that line to include a valid API key. An alternative executable demo would be the finished app, which is free on the Apple App Store under the name “emoTune: emotion tuner”.
